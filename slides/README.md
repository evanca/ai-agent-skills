# Skill slides

[AI Scope QA](ai-scope-qa.dc.html) is the editable Codex Design Canvas source for
[the approved 1920 × 1080 thumbnail](../thumbnails/ai-scope-qa.png). It uses the
selected peach background (`#FFD8C5`) and two vertically stacked repository pills.
The default fonts are Fraunces Soft for headings and Space Mono for body text.

Open the `.dc.html` file in Codex Design Canvas. Its `x-dc`, `DCLogic` and
`support.js` runtime come from the host; this source is not a standalone browser
page. The chat screenshot under `assets/` is an input inside the slide, not the
thumbnail. Export the complete slide when updating `thumbnails/ai-scope-qa.png`.
